# Module 2 Academic Demo: HTML Frames & Iframes

## 1. Syllabus Context
- **Module 2: Web Designing**: Covers HTML structures, media, frames, semantics, and layout evolution.

## 2. Academic Significance
Traditional `<frameset>` is obsolete in HTML5 and rejected by modern web standards because:
1. It breaks deep linking, URLs, and bookmarking.
2. It breaks the browser's navigation history (forward/backward buttons).
3. It creates critical accessibility barriers for screen-reading assistive technologies.
4. It is fundamentally incompatible with mobile responsive design.

## 3. Implemented Demos
1. **`legacy-frameset.html`**: A preserved historical demonstration using HTML 4.01 Frameset DTD showing top navigation and sidebar sub-windows.
2. **`modern-iframe.html`**: Demonstrates modern HTML5 inline frames with the `sandbox` security attribute, responsive styling, and integration with the application's REST endpoints.
